# Uber Trip Analysis Dashboard

## Project Overview
This project analyzes Uber trip data using Power BI to identify insights related to bookings, revenue trends, trip distance, and trip duration.  
The dashboard helps stakeholders understand ride demand patterns and improve operational efficiency.

## Key KPIs
- Total Bookings
- Total Booking Value
- Average Booking Value
- Total Trip Distance
- Average Trip Distance
- Average Trip Time

## Dashboard Pages

### 1. Overview Analysis
- KPI cards showing booking and revenue metrics
- Dynamic Measure Selector using a disconnected table
- Booking analysis by Payment Type and Trip Type
- Vehicle Type performance comparison
- Daily booking trend analysis

### 2. Time Analysis
- Booking trends by Pickup Time (10-minute intervals)
- Booking trends by Day of Week
- Heatmap showing demand by Hour and Day

### 3. Detailed Data View
- Grid table showing detailed trip records
- Drill-through functionality from charts
- Bookmark to toggle between filtered and full dataset

## Key Features
- Dynamic KPI selection using DAX
- Interactive slicers (Date, City, Vehicle Type)
- Conditional formatting for performance insights
- Dynamic titles based on selected metrics
- Tooltips for additional insights
- Clear slicer button for quick reset

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Modeling
