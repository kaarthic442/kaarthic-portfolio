# Shopify Sales Analysis Dashboard

![Shopify Dashboard](Shopify_Dashboard.png)

## Project Overview
This project analyzes Shopify sales data using Power BI to uncover insights into transaction performance, customer purchasing behavior, and long-term customer value.  
The interactive dashboard helps stakeholders understand revenue trends, customer engagement, and retention patterns to support data-driven business decisions.

## Key KPIs
- Net Sales
- Total Quantity Sold
- Net Average Order Value
- Total Customers
- Single Order Customers
- Repeat Customers
- Customer Lifetime Value (LTV)
- Repeat Purchase Rate
- Purchase Frequency

## Dashboard Pages

### 1. Sales Performance Overview
- KPI cards displaying Net Sales, Quantity Sold, and Avg Order Value
- Regional performance analysis by Province and City
- Top-performing cities comparison
- Dynamic KPI selection for interactive analysis

### 2. Customer Behavior Analysis
- Customer segmentation (Single vs Repeat Customers)
- Purchase frequency analysis
- Customer lifetime value insights
- Payment gateway usage analysis

### 3. Sales Trend Analysis
- Area chart showing daily sales trends
- Hourly sales activity analysis
- Identification of peak sales periods
- Time-based performance insights

### 4. Product Performance
- Analysis of revenue by product type
- Identification of top-selling product categories
- Comparison of order volume across product types

### 5. Detailed Data View
- Drill-through table showing transaction-level details
- Allows exploration of individual orders, customers, and products
- Helps validate aggregated insights with raw data

## Key Features
- Dynamic KPI selection using DAX
- Interactive slicers for region, product type, and time filters
- Geographic sales visualization using maps
- Drill-through functionality for detailed analysis
- Tooltips providing additional metrics and insights

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Modeling
