# Meta Ads Performance Analysis Dashboard

## Project Overview
This project analyzes advertising campaign performance on Facebook and Instagram using Power BI.  
The dashboard provides insights into campaign reach, engagement, conversions, and budget utilization to help marketing teams optimize campaign performance and ROI.

## Key KPIs
- Impressions
- Clicks
- Shares
- Comments
- Purchases
- Engagements
- Click Through Rate (CTR)
- Engagement Rate
- Conversion Rate
- Purchase Rate
- Total Budget
- Average Budget per Campaign

## Dashboard Visualizations

### 1. Audience Analysis
- Donut chart showing performance by Target Gender
- Bar chart displaying engagement across Target Age Groups
- Helps identify the most responsive audience segments.

### 2. Geographic Performance
- Map visualization showing campaign performance by Country
- Bubble size represents selected metric (Impressions, Clicks, Purchases)
- Helps understand global reach and engagement patterns.

### 3. Time-Based Analysis
- Calendar Heatmap showing monthly performance trends
- Stacked column chart showing weekly performance by Ad Type
- Area chart displaying hourly engagement trends
- Helps identify peak activity periods and campaign effectiveness.

### 4. Ad Performance Comparison
- Matrix visual comparing Ad Types across platforms (Facebook vs Instagram)
- Enables side-by-side analysis of ad formats and performance.

## Key Features
- Dynamic KPI selection using a parameter table
- Interactive slicers for campaign filtering
- Time-based trend analysis
- Geographic performance insights
- Interactive visuals for campaign comparison
